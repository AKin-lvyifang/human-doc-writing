# 用户写作画像

这里由 `$human-doc-writing` 在用户授权学习、记住或维护画像时保存。本次参考和分析不自动持久化。

- `preferences.md`：通用审美偏好与适用说明。
- `portraits/<type>.md`：兼容保留的类型默认正向画像。
- `portraits/<type>/<name>.md`：同一类型可并存的具名写法。
- `anti-patterns/`：对应的反例画像，支持同样两种路径。
- `history/`：被替换或删除的旧版本。
- `portrait-index.md`：保存或移除画像时更新的列表；脚本 `list` 可只读显示当前文件与相对路径。

一篇完整样文就能提炼可用写法，不需要手工填写 YAML。画像记录“创作选择 → 读者效果 → 适用场合与边界”。不同写法可以并存，写作时按当前任务选择；新学一篇不自动覆盖或平均旧偏好。

同名更新和移除会先保留带名称、时间的备份。使用备份文件重新 `save` 到原类型和名称即可恢复。省略 `--name` 的旧命令继续操作类型默认画像，只有明确要替换默认时才覆盖它。

升级 Skill 时必须保留整个 `user/` 目录。
