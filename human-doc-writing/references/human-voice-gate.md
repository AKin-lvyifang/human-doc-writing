# 人味统一终审

初稿完成后再读取本文件。它不负责生成第一稿，也不提供固定文风。画像和类型卡决定文章怎样说，这道门负责保护已经成立的部分，再清理事实越界、说明书口吻和模型化修辞。

写前只读取 `material-gate.md`；公众号、知乎、论坛、博客等社媒中长文再读取 `natural-social-prose.md`。不要让下面的禁令提前接管起稿。

## 先救人，再清句子

终审不是把文章修到最安全、最整齐。

- 先圈出稿子里最像一个人在处理事情的部分。可能是材料来路、普通判断、一次补充、一个真实限制或不规则的节奏。后续修改优先保护这些地方。
- 段落有真实材料但语气像报告时，改写主语、动作和因果，不直接删掉整段。
- 删除自问自答、点题金句或抽象借喻时，检查它是否遮住一条真实因果。因果存在就把动作和后果补回相邻段落；只剩姿势才整句删除。
- 去掉模型腔以后若篇幅明显变薄，回到材料补过程、条件、选择、失败和后果。不能用同义改写回填，也不能把文章删成产品说明摘要。
- 普通重复、补充、自我修正和轻微岔话只要来自材料、能帮助理解，就可以保留。不要把所有不整齐都当成错误。

## 七遍终审

### 第一遍看谁在说

回答四件事：

- 作者凭什么知道这件事。
- 哪一处能看出他真的在意。
- 哪个判断有材料托着，哪个情绪有动作托着。
- 哪几段换一个模型也能原样写出来。

第四类段落优先补信息来路、作者取舍和具体材料。没有东西可补才删除。不要靠增加“我觉得”“说真的”修复匿名感，声音来自取舍。

### 第二遍看文章怎样往前走

给每段标出主要作用和材料来源。动作、事实、解释、背景、判断与后果可以在同一段共存，不要为了标注方便把每段改成单一功能。

后一段只把前段换一种说法时合并或删除。删掉一段会失去过程、限制、决定或后果时，说明它仍有工作，不要为了压缩试验机械删掉。

核对篇幅契约。目标篇幅已经有足够材料支撑时，终审不能静默交付短稿；从现有材料中找回被过度压缩的过程和后果。材料不足时，按 `material-gate.md` 研究、追问或明确缩短。

拿写前的材料覆盖表与终稿逐项对照。标记为必须保留的动作、限制、失败和后果，要么仍能在正文里找到，要么有明确的删除理由。约 1,200 字以上的现实长稿至少保留一条读者能跟下来的实际过程；终稿只剩定义、职责关系和结论时，即使总字数合格也要退回重写。

同批多稿分别查看推进骨架。段落数、转折位置和结束方式全部一致时，回到每篇最硬的材料重新安排，不靠拆分句子伪造差异。

### 第三遍拆掉说明书与表演性中文

先清核验笔记泄漏。现实稿只在会改变结论的位置说明一次不确定性。连续出现“这里能够确认的是”“文章只讨论”“当前范围包括”，说明后台核验接管了正文。

再清方案说明书口吻。文章连续给材料命名、分组、逐项写“负责什么”，最后说明“共同构成什么”，却没有继续讲动作、选择和结果时，先还原事情本身。确实需要比较职责，写清各自做了什么、少了它会怎样。

Skill、系统和方法题优先恢复真实的安装、使用、失败与修改顺序。概念解释只能跟在需要它的动作旁边，不能连续占据正文主干。若删掉产品名以后段落仍可原样放进另一篇文章，说明它还没有回到当前材料。

圈出单独截图显得有力、放回正文却没有增加事实、解释或情绪的句子。大部分删除。连续几段都用短判断收尾，只保留真正有材料的一处。

检查假具体、假口语、抽象名词堆叠和多套借喻。现实稿没有来源的时间、天气、神态、房间、对白和心理不能留下。抽象话改成人做了什么、花了多少时间、谁承担后果。

### 第四遍听中文是否顺

- 让主语和动作早点出现，拆开过长定语。
- 同一个准确的词可以重复，不要自动换成“这项能力”“这套机制”“这一体系”。
- 删除一半可有可无的“因为、所以、但是、同时、此外、然而”。中文小句能靠语序和事理接上就不用补连接词。
- 把“进行了、实现了、完成了对、起到了作用”还原成直接动作和真实结果。
- 长句装下复杂过程，短句让事情落地。连续短句像敲桌子就合并，连续长句让人找不到落脚处就拆开。
- 检查句长和段长高低差。全文不能每段相近、每句相近，也不能为了过检查器硬塞一个极短句。
- 动作、物件或原话已经传出情绪时，删掉紧随其后的翻译。

### 第五遍清模型形状

按修辞动作检查，不只搜索字面。

- 删除翻案腔。不要先立一个读者并没有的误解，再推翻它给判断抬价。判断从正面下，再给依据。文章真的用材料走过误解与修正时可以保留一次自我修正，但不能套固定外衣。
- 三项以上同构排比只留两项，第三项换说法或删除。
- 不给抽象名词配具体动词写抒情，不让时间保管细节、焦虑显出形状、岁月磨平问题。
- 清理提示性冒号、破折号、模型路标、商业黑话、重复句首、排队式短段和模板化总结。
- 检查模型偏爱的抒情词和自造高亮短语。写具体事物时保留，给抽象概念穿衣服时删除。

社媒中长文同时执行下方严格档。

### 第六遍核事实与篇幅

现实稿核时间、数字、身份、引语、因果、产品状态和第一人称动作。虚构稿核人物知道什么、时间空间、物件和世界规则。核验说明留在后台。

再次运行篇幅检查。材料充足且文档契约有最低线时，使用 `--min-han`。篇幅不足不能靠重复解释、无来源例子或拆段补齐。

### 第七遍查结尾

分别删掉最后一段和最后两段再读。删掉更有力就让文章提前结束。

最后一段重新概括全文时先删。正文没有持续处理时代、文明、未来或世界尺度时，结尾回到具体事实、行动或当前判断。开头事物在结尾回来时，它的作用或含义必须已经发生变化。

## 所有文档都执行的通用门

- 不编造事实、经历、数据、社会证明、案例和验证结果。
- 不用空泛时代背景、文档自述和写作预告开场。
- 不把同一个意思写成正文、列表和总结三遍。
- 不用“核心”“本质”“真正”“更深一层”等抬高词代替事实差异。
- 不用商业汇报黑话给普通事情抬价。术语确有精确含义时保留。
- 不让格式接管内容。标题、列表、表格和加粗只在能帮助导航、对比或执行时使用。
- 不用固定互动口播、宏大宣言或机械总结收尾。
- 不因终审删改丢失文档契约中的必要过程、后果和最低篇幅。

## 社媒中长文严格档

适用于公众号、小红书、知乎、论坛、博客和其他社媒中长文。标题、小标题、正文、图片说明和引用转述都在检查范围内。

交稿前清零：

- 破折号、双破折号和连接号式破折号。
- 提示性中文或英文冒号。冒号只允许引出人物直接原话；网址、代码和机器字段不受影响。
- 翻案腔及其变形，包括“不是……而是……”“并非……而是……”“不在于……而在于……”“与其说……不如说……”“表面……实际……”“看似……实则……”“你以为……其实……”“回头才发现”“A 不重要，重要的是 B”。清单是举例，不是边界。
- “说白了”“说穿了”“先说结论”。
- 作为洞察路标的“更微妙的是”“还有一层”“只说对了一半”“值得注意的是”“需要指出的是”“从某种意义上说”。
- 三项以上的同构排比、给抽象名词配具体动词的抒情句，以及“进行了优化”“实现了提升”一类动词名词化。
- 用来给普通事情抬价的绝对禁词：赋能、抓手、商业闭环、价值闭环、能力沉淀、拉通、底层逻辑、顶层设计、认知跃迁、价值释放、能力建设、降本增效、内容矩阵、全链路、组合拳、打开想象空间、结构性机会、关键命题、深层逻辑、技术底座、公共底座、技术主权、单点风险、主脊柱、材料锚点、认知增量、迭代闭环。

“沉淀、颗粒度、对齐、协同、链路、生态位、心智、范式、方法论、核心变量、打法、想象空间、闭环、不丢”只做语境检查。确实表达化学、排版、生态学、学术、游戏战术、控制回路或普通本义时可以保留；只是抬价时改写。

“不只……还……”是正常递进。它只有在先立误解、再给下文抬价时才按翻案腔处理，不做字面零容忍。

公众号现实观点、复盘和产品体验稿还要清零：

- 作者自己提出、紧接着自己回答的问题，以及用疑问句转场制造悬念。现有个人画像要求公众号非虚构正文不用问号时，素材中的真实问题改成不改变含义的处境或间接引语。
- 只负责停顿、翻案或显得意味深长的孤立短判断。把有效因果并回上下文，删掉只剩姿势的句子。
- 连续的核验声明、文章范围声明和“几项能力分别负责什么”的方案说明段。改写成读者正在理解的事情、动作和后果。

## 技术与结构化文档适配

README、PRD、教程、Release、产品文档和说明文仍执行通用门，但保留这些必要形式：

- 表示键值、字段、定义和步骤结果的冒号。
- 代码、命令、URL、配置项和机器字段。
- 真正并列的列表、用于比较的表格、帮助跳读的标题。
- 准确且在项目中已有定义的术语。
- 能减少误解的对比句。

不要因为形式合法就保留空洞内容。标题下面没有新事实，列表只是把一句话拆成多项，术语可以换成普通动作却仍被用来抬价，都需要改。

## 自动检查

所有 Markdown 或纯文本成稿都运行检查器。

```text
python3 scripts/lint_ai_style.py 稿件.md --profile universal --strict
python3 scripts/lint_ai_style.py 社媒稿.md --profile social-longform --strict
python3 scripts/lint_ai_style.py 公众号稿.md --profile wechat-longform --strict --min-han 1200
python3 scripts/compare_draft_shapes.py 稿件一.md 稿件二.md 稿件三.md --strict
```

`--min-han` 只在文档契约和材料门已经确认最低篇幅时传入。批量结构检查只提示同构风险，必须回到材料判断；不能为过检查器机械拆段。

脚本只发现文字形状。硬项以外的警告需要人工判断；脚本通过不代表事实、材料和人味已经通过。

## 最后冷读

暂时忘掉所有规则，只回答六个问题。

1. 哪里让我相信作者确实知道这件事。
2. 哪里让我愿意继续读。
3. 哪一段像人在处理一个问题，哪一段像产品说明或模型在完成任务。
4. 哪句话说得比材料大。
5. 去掉 AI 腔以后，哪些必要过程或后果被一并删掉了。
6. 写前标记为必须保留的材料，终稿是否仍能逐项找到。
7. 文章在哪一句已经结束。

有一个问题答不上来，就回到对应段落再改。
