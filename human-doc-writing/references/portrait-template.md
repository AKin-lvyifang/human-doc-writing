# 写作画像模板

由 Skill 按实际样文填写，保留有用栏目，删除空项。使用普通 Markdown，不需要 YAML。篇幅由有价值的观察决定，不为模板补齐泛泛规则。

```markdown
# 温厚的生活观察

- 类型：随笔/散文/读书
- 写法名称：warm-observation
- 来源：用户提供的样文标题或文件/链接
- 建立时间：YYYY-MM-DD
- 画像范围：由单篇样文提炼的可选写法
- 适用场合：有真实细节可展开的生活随笔
- 不适用情境：需要快速查阅操作或作出明确决策的文档

## 给读者的体验

用简短文字描述读者怎样进入、理解或感受文章，以及作者与人物、读者保持的距离。

## 值得复用的选择

### 一项真正影响阅读的选择

选择：作者怎样观察、安排材料或使用语言。
效果：它如何帮助读者理解、推进叙事或形成感受。
适用与边界：什么条件下有效，缺少什么材料或面对什么任务时需要换写法。

按需继续记录开头、推进、节奏、细节或收束，不固定规则数量。

## 本次写作优先参考

提炼最有用的少量选择。说明必须满足的材料条件，避免把所有特征变成全篇反复出现的招式。

## 原创对照（可选）

换一个主题，用简短自写片段演示一次选择，并解释效果。标明这是虚构演示，不带入下一篇纪实稿。

## 不随画像迁移

样文的作者身份、经历、事实、数据、观点、独特句子和意象。用于新稿时重新依据本次材料选择结构与细节。
```

反例标题标为“避坑画像”，主要条目写“造成阅读问题的选择 → 具体阅读影响 → 何时需改、怎样改”。不要把一次失败推成某种修辞或文体的通用禁令。
