# 类型写作卡：小红书内容 `xiaohongshu`

## 适用范围

适合小红书经验、教程、清单和测评类笔记。重点是让读者快速获得一个可用结论，同时保留真实边界。

常见子类型：

- `experience`：真实经验复盘。
- `tutorial`：短教程。
- `checklist`：筛选或行动清单。
- `review`：基于真实使用材料的测评。

## 读者结果

读者在快速扫描后，知道结论、适用对象、关键步骤或注意事项。

## 写前必须确认

1. 最重要的结论或核心主题。
2. 是否有真实第一手经历或数据。
3. 读者最在意的成本、效果和限制。
4. 希望读者收藏、尝试还是避坑。

写前执行 `../human-voice-gate.md` 的事实与材料门。篇幅较短时不机械要求五件材料，但亲历、数据、人物和效果仍要有来源，不能用平台口吻掩盖材料不足。

## 可选结构

### 经验复盘

结果或变化 → 原来遇到的问题 → 做了什么 → 哪一步最关键 → 不适用情况。

### 短教程

目标结果 → 前置条件 → 3～6 个关键步骤 → 常见坑 → 完成标志。

### 清单

适用场景 → 筛选标准 → 分组清单 → 一个关键提醒。清单必须同层级，不能为了凑数硬写十条。

### 测评

使用背景和条件 → 核心结论 → 关键维度 → 明显缺点 → 适合与不适合谁。

## 标题与开头

- 标题简洁具体，优先写对象、结果或问题。
- 第一段直接给结论、变化或痛点。
- 没有亲身经验时，不写“亲测”“用了三个月”“身边人都在用”。
- 不用夸张数字、绝对承诺和虚假稀缺。

## 正文

- 允许短段落和留白，但不能把每句话拆成海报文案。
- 重点信息可以用少量列表，避免每行都配 emoji。
- 先给最有用的内容，再补背景。
- 清楚写成本、限制和不适用人群。
- 标签只保留与主题直接相关的词，不堆热点。

## 结尾

用一个行动建议、适用边界或最终判断结束。不要自动生成“姐妹们快冲”“错过后悔”等伪熟人话术。

## 语言与节奏

轻、快、具体。可以口语化，但不能装熟、装体验、装热闹。表情符号和感叹号按用户风格使用，不是平台入场券。

## 常见 AI 痕迹

- 标题塞满夸张词和感叹号。
- 开头先讲一大段背景，迟迟不给结论。
- 机械使用“三个步骤、五个技巧、七个坑”。
- 每行一个 emoji 加半句话。
- 虚构亲测、销量、用户反馈和效果。
- 结尾强行催互动或制造焦虑。

- [ ] 所有经验和数据有来源。
- [ ] 步骤或清单同层级、可执行。
- [ ] 明确写了限制，不用绝对承诺。
- [ ] 没有靠 emoji、单句排队、假熟络和虚构场景制造活人感。
