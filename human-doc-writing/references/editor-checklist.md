# 编辑查漏

仅在需要查漏时按文体与修改范围选择，已检查且无新问题的内容不重复处理。

- 是否适合读者、场合与文体，平台是否不当地决定整篇文风。
- 观察与判断是否具体，有无假经历或固定口头禅。
- 能否跟上概念、因果、动作与情绪，哪里需补关系，哪里可略过。
- 有表现力的细节与语言是否保住，文学表达是否适合本篇用途。
- 每段是否对理解、叙事、感受或节奏有用，有无无效重复。
- 修辞是否有作用，有无误把有效表达当禁项。
- 文体底线是否完整：教程条件与成功标志、PRD 规则与验收、发布变化与影响等。
- 事实、引语、推测与假设是否分清，来源和不确定性是否准确。
- 是否按本次要求与匹配画像选择文风，有无误套旧平台画像。
- 局部改稿有无扩大范围，是否丢失意义、条件、声音或约定篇幅。
- 是否清除内部过程残留，保留读者需要的公开来源和待决策项。
- 是否按内容而非脚本分数决定修改，多稿有无为差异故意改段数。
