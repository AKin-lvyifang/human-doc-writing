# 长文与多稿编排

只有存在可独立完成的来源核对、内容模块或不同交付物，且并行有明显收益时，才组织子智能体。普通短文、紧密叙事或耦合论证直接完成，不因篇幅或标题数增加角色。

## 主 Agent 的职责

保持本篇读者、文体、作者位置、表达选择、事实口径与最终文件的一致。把这几项和不可遗漏内容简短传给协作者，不额外要求固定合同表或角色数量。

- 连续叙事：由主 Agent 完成最终正文；协作者可核对来源、分析人物/事件材料或提供阅读反馈，不按标题分别创作后拼接。
- 模块文档：可独立梳理模块，提供必要草稿；整合时统一术语、接口、语气和导航，有问题的部分才重写。
- 多份交付：各份按读者任务选择文体和声音，共享事实与必要的术语。系列内容可保留一致导航，不为形式差异改段数。

最终目标文件由主 Agent 统一修改；协作者在独立草稿中工作，不竞争同一路径。

## 分派与整合

给每个协作者明确范围、材料、所需结果与边界。资料核对返回可确认事实、来源、冲突和缺口；编辑反馈定位读者断点、有作用的表达及具体修改理由。不要让每个角色都完整写一遍全文。

主 Agent 等待需要的结果，解决事实冲突后成稿。整合重点是各部分怎样接续、信息是否重复、不同声音是否适合本篇，而非把每段磨成相同长度。

没有子智能体时自己完成必要核对，不按角色模拟多轮任务。

## 何时拆分交付物

主要读者、阅读时机、维护方式、公开范围或事实权限明显不同，且合在一起妨碍使用时，才拆成多份正文或附录。长文可以包含多个相关模块，不按字数或目录层数自动拆分。

最终按主 Skill 的读者编辑与必要检查交付，不因并行额外增加一套终审。
