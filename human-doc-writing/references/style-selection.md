# 自主选择表达方式

文风从作者怎样看、怎样讲形成。先依据本次任务选实质文体，再根据读者与场合选择少量相容的表达特征；清澈、锋利、温厚、克制抒情、轻巧幽默等只是可能的方向，不是固定菜单。

## 先辨认写作位置

- **作者站在哪里。** 是亲历者、观察者、材料整理者、讲解者还是作出判断的人？什么值得他在意，哪些部分有把握，离人物和事件多近？文章的声音不能超出材料允许的身份与所知范围。
- **读者已经知道什么。** 什么可以直接说，什么需要铺垫，哪里最容易理解错？专业读者可以直接进入分歧，陌生读者可能先需要一个具体例子。
- **读者此刻怎样读。** 正在操作时需要可靠指引，作决定时需要判断依据，连续阅读时可以承受渐进揭示和情绪停留。平台提供线索，实际用途决定取舍。
- **本次偏好是什么。** 优先采用当前明确要求、用户认可的样文及适用画像。没有这些材料时自主选择，不因风格尚未被命名而停下来追问。

## 把文风落实到写作选择

一个内部判断就够，例如“给第一次接触的人讲清机制，从熟悉的例子进入，重要关系慢慢解释，语气耐心而轻快”。不需要生成分数、参数表或额外策划稿。

| 选择 | 具体落实 |
|---|---|
| 选材与着眼点 | 清澈的说明重视能解释机制的例子；温厚的人物稿重视体现关系与处境的细节；锋利的评论重视足以改变判断的事实与取舍。 |
| 揭示顺序 | 需要行动时尽早给答案；需要理解来由时先补关键条件；叙事或随笔可以逐渐展开，只要读者始终有可跟随的线索。 |
| 叙述距离 | 贴近人物时让动作和有依据的感受进入视野；拉远时用概述理解更长过程；讲解时与读者并肩走过推理。 |
| 节奏与停留 | 陌生关系、关键选择或有表现力的时刻充分展开；熟悉背景和重复过程略写。句长、段落和停顿随内容变化，不按固定比例混搭。 |
| 修辞分寸 | 类比帮助理解，意象承载感受，重复可以推进情绪，幽默可以减轻阅读负担。采用后检查是否准确、有作用、与全文声音相容。 |

## 同一平台可以有不同声音

以下场景用于帮助判断，不是文章模板。

| 场景 | 适合的选择与理由 |
|---|---|
| 公众号向新手解释一个技术概念 | `explainer`；从熟悉现象到关键关系，例子贴近读者经验，语言清澈而耐心。文学分寸体现在准确与流畅。 |
| 公众号评论一次行业决策 | `commentary`；围绕决定性事实和代价展开，判断鲜明，反方解释得到公平对待。锋利来自辨析而非嘲讽。 |
| 公众号写普通人的工作生活 | `narrative`；选取有来源的动作与关系细节，关键时刻放慢，语气可以温厚，也可以疏朗克制。 |
| 公众号写一次阅读带来的感受 | `essay`；沿具体语句、意象或观察形成联想，允许停留与回望，用词有节制，读者能跟上感受的来由。 |

## 何时调整

初稿如果只剩形容词变化，回到选材与揭示顺序；如果文学表达使动作、规则或因果变模糊，先恢复清楚的意思；如果删改后声音过于平整，恢复确有作用的节奏、细节、情绪或修辞。按读者实际获得的理解与感受判断，不以“装饰更多”或“禁词更少”作为改进。

一篇文章可以随内容改变速度和温度，但保持可信的作者位置。不要为了展示风格储备，让相邻段落突然换成互不相容的声音。写作方法和全文编辑分别沿主 SKILL 的对应参考执行，本文件只负责选择方向。
