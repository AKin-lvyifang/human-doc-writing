# 模板 / Templates

这些参考帮助记录有效的写作选择，并非每次写作都要填写的表格。

- [portrait-template.md](portrait-template.md)：用“创作选择 → 读者效果 → 适用条件”记录一种具名写法，只保留样文中有依据、有用途的栏目。
- [portrait-example.md](portrait-example.md)：温厚的生活观察画像示例，展示怎样记录细节选择与叙述节奏；属于原创演示，不代表已确认的用户偏好。
- [brief-template.md](brief-template.md)：仅在缺失信息实质改变方向、关键事实或交付范围时，帮助提出简短澄清。要求清楚时直接写，不例行发送确认卡。

个人画像保存在 Skill 的 `user/` 中，不自动复制到本目录。升级时请完整保留原有 `user/`。

---

These references help record useful writing choices. They are not forms to complete for every writing task.

- [portrait-template.md](portrait-template.md): record a named approach as “creative choice → reader effect → conditions for use,” retaining only sections supported by and useful for the sample.
- [portrait-example.md](portrait-example.md): an illustrative profile for warm observations of everyday life, showing detail selection and narrative pacing. It is an original demonstration, not a confirmed user preference.
- [brief-template.md](brief-template.md): support brief clarification only when missing information materially changes direction, key facts, or scope. Clear requests proceed directly, without a routine confirmation card.

Personal profiles remain in the skill's `user/` directory and are not copied here automatically. Preserve the complete existing `user/` directory when upgrading.
