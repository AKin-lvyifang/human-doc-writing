# 模板 / Templates

- `portrait-template.md`：画像灌输时使用的普通 Markdown 模板。
- `portrait-example.md`：不包含个人或项目事实的说明文画像示例。
- `brief-template.md`：长文执行前的简短确认卡示例。

这些模板来自 Skill 的现有公开结构。真实用户画像不会自动进入本目录。

---

- `portrait-template.md`: plain Markdown structure for an ingested profile.
- `portrait-example.md`: generic explainer-profile example without personal or project facts.
- `brief-template.md`: short pre-writing brief example for long-form tasks.

These templates mirror the public skill structure. Active user profiles are never copied here automatically.
